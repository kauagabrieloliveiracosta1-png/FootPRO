FOOTPRO V0.1 — PACOTE INICIAL
================================

COMO ABRIR
1. Extraia o arquivo ZIP.
2. Abra a pasta FootPRO_V0.1.
3. Clique duas vezes em index.html para abrir no Chrome, Edge ou Firefox.
4. Clique em NOVA CARREIRA, crie seu treinador e escolha um clube.
5. Use o menu para administrar elenco, táticas, calendário, competições, mercado e demais áreas.

ARQUIVOS
- index.html: entrada do jogo.
- style.css: interface responsiva.
- app.js: regras e lógica da carreira.
- assets/: pasta reservada para recursos visuais futuros.

SALVAMENTO
A carreira é salva automaticamente no armazenamento local do navegador. Ela fica vinculada ao navegador e dispositivo usados. Use Configurações > Baixar backup para exportar um arquivo JSON. Não limpe os dados do navegador sem antes exportar o save.

IMPORTANTE SOBRE O ESCOPO
Este é o primeiro build funcional e jogável, não a implementação final de todos os sistemas do planejamento. A V0.1 inclui uma carreira local com elenco gerado, gestão básica, táticas, partidas simuladas, classificação, calendário, mercado simplificado, finanças, treinamento, scouting, base, comissão, infraestrutura, notícias, patrocínios, editor e backup.
O banco inicial contém uma seleção demonstrativa de clubes e jogadores gerados para teste. Não é uma base oficial completa, não possui licenças de marcas/escudos e não sincroniza transferências reais.
Sistemas avançados como ligas mundiais completas, calendário oficial por país, regras FIFA detalhadas, partidas com narração de áudio, animações, VAR aprofundado, imprensa online, atualizações automáticas, multiplayer e integração online exigem desenvolvimento adicional, dados e/ou serviços externos. As áreas de menu não devem ser confundidas com todos esses sistemas já finalizados.
O jogo foi desenhado para evoluir em módulos e preservar os saves quando possível.

REQUISITOS
Navegador moderno com JavaScript ativado. Para abrir localmente não é necessário instalar servidor nem estar conectado à internet. A fonte externa é opcional; se não houver conexão, o navegador usa fontes padrão.
